# Presentation

This is a utility discord bot made to serve as an alternative to paid administrations bots. It embeds functions mainly designed for small / medium servers

# Requirements
* NodeJs
* Bun
* Docker or Postgresql Server

# Installation
First clone this repository
```bash
git clone https://github.com/Shiruaru/Izuna-Hatsuse
cd Izuna-Hatsuse
```

Then run the docker compose, unless you have an available postgresql server
```bash
socker compose up -d
```


Finally install all the dependencies and run the bot
```
bun install && bun start
```
